# 收费工单 · 数据看板设计

## Context

`pages/charge-order/index` 的"数据看板" Tab 当前只有占位级 mock —— 4 个硬编码 KPI、1 张月度柱状图、1 张维修方饼图、1 个维修方 TOP 5 榜单 —— 维度选取偏随意，缺乏聚焦。

本次设计基于收费工单 store (`pages/charge-order/store.js`) 已有字段，围绕"**成本监控 + 热点定位**"两条主线，重做数据看板，使之真正为行政/运营视角服务。

**范围限定**：本轮只做前端 UI 与基于 mock 数据的聚合演示。不涉及云函数、后端数据库、真实数据接入 —— 未来切换后端时再单独迭代，不在本 spec 内。

---

## 用户意图

- 主看板关心：哪些设备/楼层问题最多、月度支出、分类占比、总支出
- 使用者：管理层/运营视角（非财务视角，非维修员个人视角）
- 时间筛选：顶部 Segmented，本月/上月/本季度/本年/自定义，默认"本月"；KPI、占比、热点随筛选联动；**月度趋势图固定"近 12 个月"不受筛选影响**
- 热点度量：按**工单数**（不是按费用）
- 分类占比维度：**`order_category`**（工单分类，如 中央空调/电梯/消防/强电）
- 移除现有"维修方 TOP 5"榜单（精简）

---

## 页面结构

数据看板 Tab 从上到下：

```
├─ 时间筛选器 Segmented
├─ KPI 网格（2×2，4 张小卡）
├─ 趋势图卡（近 12 个月支出）
├─ 分类占比卡
├─ 楼层 TOP 条形图卡
└─ 设备 TOP 条形图卡
```

线性堆叠、统一卡片风格、无 Tab 内分组。

---

## 1. 时间筛选器

**位置**：数据看板滚动区最顶。

**UI**：复用列表 Tab 已有的 Segmented（`.segmented` / `.seg-item` / `.seg-active`），5 个选项：`本月 / 上月 / 本季度 / 本年 / 自定义`。

**默认**：选中"本月"。

**自定义**：点击弹出 date range picker，复用编辑页的 `.modal-overlay` + `picker mode="date"` 组合。选定后，Segmented 上该项文字切换为实际日期 `04/01-04/20`。

**状态管理**（`index.js` data）
- `activeRange: '本月'`
- `customRange: { start: '', end: '' }`

切换 range 时调用 `computeDashboard(range)` 重算 KPI / 占比 / 热点。

---

## 2. KPI 4 卡网格

**布局**：2 列 × 2 行 grid，卡片沿用当前 `.kpi-card` 样式（白底 / 微阴影 / 圆角），每张卡包含 `标签` / `数值` / `环比小标签`。

| 卡片 | 数值 | 算法 |
|---|---|---|
| 总支出 | `¥123,456` | 周期内 `totalAmount` 求和；**数值红色**（呼应详情页总费用配色） |
| 工单数 | `48` | 周期内收费工单总数 |
| 平均单次费用 | `¥2,572` | 总支出 ÷ 工单数（向下取整） |
| 环比变化 | `↑12.3%` | (本期总支出 − 上期) / 上期；上期 = 等长度的前一区间 |

**环比配色**：上升红↑ / 下降绿↓（上升表示花得更多，警示意味）。配色通过 wxss 变量集中定义，后续要改成中性蓝色只需改一处。

---

## 3. 月度支出趋势图

**类型**：柱状图（沿用当前 `trendOption` 的柱状形态）。

**范围**：近 12 个月，**不随时间筛选器变化**。

**样式**
- X 轴：12 个月标签（`5月…4月`，最新月在右）
- Y 轴：金额，自动刻度，`¥10k` 简写
- 柱色：蓝渐变（顶 `#3b82f6` → 底 `#60a5fa`）
- 柱宽 12~14px，圆角 4rpx
- 点击柱显示 tooltip `X月 ¥12,340`

**卡片**：标题"月度支出趋势"，右侧灰字"近 12 个月"；图表区 `height: 200px`。

**mock 数据**：index.js 顶部硬编码 12 条 `{ month, amount }`。

---

## 4. 分类占比图

**类型**：环形图（Donut）。

**维度**：`order_category` 聚合 `totalAmount`。

**样式**
- 最多 5 类 + "其他"合并（第 6 起归入其他）
- 配色：`['#3B82F6', '#06B6D4', '#F59E0B', '#EF4444', '#10B981', '#94a3b8']`（其他 = 灰）
- 半径：外 `60%` / 内 `42%`
- 中心：小字"总支出" + 大字金额
- 右侧图例：每行"● 电梯 · 42%"

**卡片**：标题"按工单分类费用占比"；图表区 `height: 240px`。

v1 不做扇区点击高亮/联动筛选。

---

## 5. 楼层 / 设备 TOP 条形图

两张卡对称，仅维度不同；各自独占一张卡。

**类型**：横向条形图 TOP 5。

**样式**
- X 轴：工单数（整数刻度）
- Y 轴：维度标签；排名降序从上到下
- 柱色：楼层卡 = 琥珀 `#F59E0B`；设备卡 = 青 `#06B6D4`
- 柱高 ≈ 22px，右端圆角 6rpx
- 每条柱右侧显示 `{{count}} 单`

**数据**
- 楼层：按 `floor` 字段分组 count
- 设备：按 `order_category` 分组 count（与占比图共用字段，分析角度不同）

**标题**
- "楼层维修热点 TOP 5" / "设备维修热点 TOP 5"（右侧灰字 "按工单数"）
- 每张卡 `height: 220px`

**空态**
- 数据少于 5 条：按实际条数显示
- 0 条：卡内显示"暂无数据"

## Mock 数据扩充

现有 `store.js` 的 `ORDERS` 只有 5 条记录且全部集中在 2026-04（4 月份），不足以让时间筛选器"本月/上月/本季度/本年"切换出视觉差异。实施时需在 `ORDERS` 数组末尾追加若干条**跨越过去 12 个月**的工单（不同 `created_at` / `order_category` / `floor` / `totalAmount`），每月 3~8 条足够看板呈现可信分布。

此外 `trendData` 12 个月数据作为独立 mock 数组写在 `index.js` 顶部（与 ORDERS 解耦，方便调整趋势视觉效果）。

## 验证

1. 打开微信开发者工具，进入 `charge-order/index` → 切到"数据看板" Tab
2. 顶部 Segmented 5 选项可点击切换；默认"本月"高亮
3. 切换"上月 / 本季度 / 本年"—— KPI 4 卡、占比饼图、两张热点图的数值/图形应刷新；月度趋势图保持不变
4. 点"自定义" → 弹窗 → 选日期范围 → 确定 → Segmented 该项显示为实际日期范围
5. 视觉核查
   - KPI 卡片：总支出红、其余正常色，环比箭头方向与颜色配对正确
   - 趋势柱状图：12 个月柱体，蓝渐变，点击有 tooltip
   - 分类环形图：中心显示周期总支出，右侧图例 5~6 行
   - 楼层 TOP / 设备 TOP：琥珀/青色横向条形，右端显示"X 单"
6. mock 数据稀疏时：热点图条数自动少于 5，0 条时显示"暂无数据"
7. 整页滚动顺畅，卡片间距一致
