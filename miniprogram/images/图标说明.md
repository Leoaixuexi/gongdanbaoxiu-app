# 登录页面图标说明

## 需要的图标文件

请将以下4个图标文件放置在 `miniprogram/images/` 目录下:

### 1. user-icon.png
- **用途**: 用户名输入框左侧图标
- **尺寸**: 建议 40x40px (或80x80px @2x)
- **颜色**: 白色或浅色(适配深色背景)
- **样式**: 用户头像轮廓图标
- **推荐来源**:
  - Lucide Icons: User 图标
  - Feather Icons: user
  - Material Icons: person_outline

### 2. lock-icon.png
- **用途**: 密码输入框左侧图标
- **尺寸**: 建议 40x40px (或80x80px @2x)
- **颜色**: 白色或浅色(适配深色背景)
- **样式**: 锁图标
- **推荐来源**:
  - Lucide Icons: Lock 图标
  - Feather Icons: lock
  - Material Icons: lock_outline

### 3. eye-icon.png
- **用途**: 密码可见状态图标(显示密码)
- **尺寸**: 建议 40x40px (或80x80px @2x)
- **颜色**: 白色或浅色(适配深色背景)
- **样式**: 睁开的眼睛图标
- **推荐来源**:
  - Lucide Icons: Eye 图标
  - Feather Icons: eye
  - Material Icons: visibility

### 4. eye-off-icon.png
- **用途**: 密码隐藏状态图标(隐藏密码)
- **尺寸**: 建议 40x40px (或80x40px @2x)
- **颜色**: 白色或浅色(适配深色背景)
- **样式**: 闭上的眼睛图标(通常带斜线)
- **推荐来源**:
  - Lucide Icons: EyeOff 图标
  - Feather Icons: eye-off
  - Material Icons: visibility_off

## 图标获取方式

### 方法1: 使用 Lucide Icons (推荐)
1. 访问 https://lucide.dev/icons
2. 搜索并下载所需图标
3. 下载为PNG格式,白色填充
4. 重命名为对应文件名

### 方法2: 使用 Iconfont (阿里巴巴矢量图标库)
1. 访问 https://www.iconfont.cn
2. 搜索相关图标
3. 下载PNG格式(白色)
4. 重命名为对应文件名

### 方法3: 使用设计工具生成
使用 Figma/Sketch/Photoshop 自行设计:
- 画布尺寸: 80x80px
- 图标颜色: #FFFFFF
- 导出格式: PNG
- 背景: 透明

## 临时替代方案(如果暂时没有图标)

如果暂时无法获取图标文件,可以使用以下临时方案:

### 方案A: 使用文字代替
修改 WXML,将 `<image>` 替换为 `<text>`:

```xml
<!-- 用户名图标 -->
<view class="input-icon">
  <text class="icon-text">用</text>
</view>

<!-- 密码图标 -->
<view class="input-icon">
  <text class="icon-text">密</text>
</view>

<!-- 眼睛图标 -->
<view class="input-eye-icon" bindtap="togglePasswordVisibility">
  <text class="icon-text">{{passwordVisible ? '显' : '隐'}}</text>
</view>
```

对应 WXSS:
```css
.icon-text {
  font-size: 28rpx;
  font-weight: bold;
  color: rgba(255, 255, 255, 0.9);
  filter: drop-shadow(0 2rpx 4rpx rgba(0, 0, 0, 0.3));
}
```

### 方案B: 使用微信icon组件
```xml
<icon type="search" size="20" color="#ffffff" />
```

但微信提供的图标样式有限,不推荐。

## 已修复的问题

✅ **登录按钮宽度和居中问题**
- 添加 `display: flex` 和 `justify-content: center`
- 添加 `align-items: center` 垂直居中
- 添加 `box-sizing: border-box` 确保宽度计算正确
- 移除 `line-height` 和 `text-align`,使用flex布局替代

✅ **图标结构**
- 已从 emoji 改为 `<image>` 标签
- 图标路径统一使用 `/images/` 目录

✅ **样式类名**
- `.icon-emoji` 改为 `.icon`
- 保持与原版完全一致
