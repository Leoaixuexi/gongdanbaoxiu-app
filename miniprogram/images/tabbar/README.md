# TabBar 图标说明

请在此目录下放置以下图标文件（建议尺寸：81x81px）：

## 需要的图标：

1. **home.png** - 工作台图标（未激活状态）- 绿色小房子图标
2. **home-active.png** - 工作台图标（激活状态）- 绿色填充小房子图标

3. **message.png** - 消息图标（未激活状态）- 灰色对话气泡图标
4. **message-active.png** - 消息图标（激活状态）- 蓝绿色填充对话气泡图标

5. **profile.png** - 我的图标（未激活状态）- 灰色用户头像图标
6. **profile-active.png** - 我的图标（激活状态）- 绿色用户头像图标

## 颜色规范：
- 未激活颜色：#7A7E83 (灰色)
- 激活颜色：#0CA77D (绿色)
- 消息激活颜色：#00C9C9 (蓝绿色，参考设计图)

## 参考样式：
参考提供的UI设计图，底部导航栏采用圆润的图标风格，带有轻微的阴影效果。
